1. Cuándo se usa CA-GEN
 CA-GEN es obligatorio para que la UX nunca se rompa. Se activa cuando el usuario solo dice "calabaza", no sabe si
 es calabacita o fruto maduro, no encuentra su variedad, no reconoce el tipo cultural, o quiere avanzar rápido con
 datos incompletos.

     Campo                                  Valor CA-GEN v2

     Cultivo                                Calabaza

     Clave interna                          CropKey.squash

     ID perfil                              CA-GEN

     Nombre mostrado                        Calabaza

     Nombre interno                         Calabaza genérica / SKIP

     Usuario ve SKIP                        No. Nunca mostrar "SKIP" ni "datos incompletos" como falla.

     Especie base                           Cucurbita spp.

     Órgano objetivo                        Fruto genérico; no decide tierno/maduro al inicio.

     Arquitectura asumida                   Semiarbustiva a semi-rastrera; cobertura media.

     Confianza inicial                      Media si hay fecha de siembra; baja si no hay fecha ni tipo.

               Principio: CA-GEN no busca rendimiento máximo ni calendario exacto. Busca no dejar al agricultor sin
               protección mientras BIO-G obtiene más contexto.



 2. Filosofía del perfil genérico
 1       No adivina: si el usuario no sabe el tipo, el sistema no inventa variedad ni destino.
 2       Protege: prioriza agua, temperatura, suelo y polinización en ventanas críticas.
 3       No exagera: las alertas tienen ponderación intermedia-alta, no extrema, salvo floración/cuajado con estrés
         claro.
 4       Migra: si después el usuario elige italiana, criolla, Castilla, pipián, etc., se recalcula sin perder historial.
 5       Es flexible: puede comportarse como calabacita si hay corte temprano o como calabaza madura si el fruto
         sigue desarrollándose.


 3. Supuesto agronómico conservador
 La mejora principal frente a la base es que CA-GEN ya no se amarra únicamente a una calabacita intermedia. En
 México, "calabaza" puede significar fruto tierno o fruto maduro. Por eso CA-GEN usa una ruta central con
 cosecha flexible.

     Parámetro                               Valor conservador

     Uso                                     Fruto genérico. No decide tierno/maduro.

     Floración probable                      40-60 días desde siembra.

     Cuajado probable                        45-75 días.

     Primera cosecha probable                60-95 días si se comporta como calabacita/criolla intermedia.

     Extensión posible                       90-130 días si el sistema detecta/usuario busca fruto maduro.

 7. Ponderación conservadora de alertas

  Alerta                                  Peso CA-GEN                 Cuándo subir peso

  Déficit hídrico                         Medio-alto                  Subir a crítico en floración/cuajado o si la tendencia cae varios días.

  Exceso de humedad / anoxia              Medio-alto                  Subir si suelo pesado, resistencia alta o HR/lluvia persistente.

  Estrés térmico                          Medio                       Subir a alto en floración/cuajado con >32 C o noches cálidas.

  Riesgo de polinización                  Medio-alto                  Subir con lluvia, nublado/frío, calor fuerte o baja actividad de abejas.

  Compactación                            Medio                       Subir en establecimiento y vegetativo temprano.

  Salinidad                               Media                       Subir si coincide con déficit hídrico o cuajado.

  K bajo en fruto                         Medio                       Subir desde cuajado/desarrollo de fruto.

  N excesivo en floración                 Media                       Subir si hay mucho follaje y poco cuajado.

  Riesgo sanitario foliar                 Medio                       Subir con HR alta, follaje denso, lluvia y etapa 4-8. [S8]



 8. Mensajes humanos CA-GEN

  Situación                                   Mensaje BIO-G recomendado

  Calor en floración                          La calabaza está en una etapa delicada. Con este calor puede haber flor, pero menos fruto
                                              si baja la polinización.

  Suelo seco en cuajado                       Ahorita no conviene que le falte agua. La planta puede tirar flor o no sostener los frutos
                                              pequeños.

  Suelo saturado                              Hay demasiada humedad. La raíz de calabaza necesita oxígeno; si se mantiene así, puede
                                              debilitarse.

  K bajo en fruto                             El fruto ya está pidiendo más potasio. No es solo crecer hoja, es sostener llenado.

  N alto y poco cuajado                       La planta puede estar yéndose mucho a hoja. Conviene revisar si sí está amarrando fruto.

  No sabe tipo                                Seguimos con una lectura segura de calabaza. Después puedes elegir el tipo sin perder
                                              historial.

     10. No usar CA-GEN cuando...
•
     El usuario eligió claramente calabacita italiana/zucchini, criolla, bola, Castilla, butternut, chilacayote o pipián.
•
     La variedad comercial ya está mapeada a un perfil Bio-G específico.
•
     El cultivo tiene intención explícita de semilla/pepita: usar CA-07.
•
     El usuario está en hidroponía/sustrato inerte: no cubrir en v1 salvo modo futuro separado.
•
     El usuario necesita dosis exacta de fertilización: Bio-G debe pedir análisis de suelo o usar guía local, no CA-GEN
     como receta.

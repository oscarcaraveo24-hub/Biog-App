6. THRESHOLDS UNIVERSALES
thresholds:
- airTemp.optimal: 15-25
- airTemp.observe: 25-28
- airTemp.alert: >28 sustained
- airTemp.critical: >30 sustained
- germinationSoilTemp.optimal: 15-22
- germinationSoilTemp.alert: >26
- soilMoistureAW.optimal: 60-95
- soilMoistureAW.lowAlert: <50
- soilMoistureAW.saturationAlert: prolonged saturation
- pH.optimalMineral: 6.0-6.8
- pH.observe: 5.8-6.0 or 6.8-7.2
- pH.alert: <5.8 or >7.5
- ECe.optimal: <1.3
- ECe.observe: 1.3-2.0
- ECe.alert: >2.0
- ECe.critical: >3.0
- compaction.alert: >=2.0 MPa
- relativeHumidity.risk: >85 sustained

8. SUBINDICES
- waterIndex: humedad suelo, saturacion, riego estable
- temperatureIndex: temperatura ambiente/suelo, calor acumulado
- soilIndex: pH, ECe, compactacion
- nutritionIndex: inferido por etapa + sintomas + reportes
- healthIndex: condiciones de riesgo + reportes visuales

9. REGLAS DE ALERTA
- if stage in E4/E5 and airTemp >28 sustained -> heatStressAlert
- if stage in E4/E5 and airTemp >30 + waterStress -> boltingCriticalAlert
- if soilMoistureAW <50 and stage in E3/E5 -> waterDeficitAlert
- if soilSaturation prolonged -> anoxiaRootAlert
- if ECe >2.0 -> salinityAlert
- if compaction >=2.0 -> compactionAlert
- if RH >85 sustained and stage in E3/E5 -> fungalRiskAlert
- if userReport.tipBurn -> tipBurnDiagnostic
- if userReport.centralStemElongating -> boltingConfirmedOverride

- daysRange: min/max
- qualityIndex: 0-100
- qualityLabel: excelente | buena | reducida | enRiesgo

No output:

- fecha unica exacta sin rango
- promesas de rendimiento

12. UX RECOMMENDATIONS
Dashboard:
- etapa actual
- dias en etapa
- ventana de cosecha con rango
- banner si calor/bolting
- indice de calidad

Crop Care:
- riego: humedad estable
- nutricion: etapa NPK relativa
- sanidad: riesgos activos por etapa
- suelo: pH/ECe/compactacion si disponibles

Notifications:
- calor E4/E5
- humedad baja E3/E5
- salinidad >2.0
- revisar campo 3-7 dias antes de cosecha
- cosecha en ventana optima
- bolting confirmado/inminente

13. REGLAS DE ORO PARA CODEX/CLAUDE
- No crear cultivo separado por tipo.
- No crear etapa de floracion productiva.
- No meter hidroponia en v1.
- No prometer dosis de fertilizante ni pesticida.
- No perder memoria al migrar LE-GEN.
- No mostrar la palabra SKIP al usuario.
- No usar kg/ha como salida principal.
- No tratar LE-05 como cabeza.
- No usar Ca/Mg/S como logica activa v1.
- Si hay discrepancia con enums reales, adaptar a los enums existentes.

NOTA SOBRE FOROS / PRACTICA DE PRODUCTORES
Se reviso la logica practica que suelen repetir productores y tecnicos: calor + falta de agua = bolting/amargor; exceso de humedad = pudriciones; crecimiento demasiado rapido + mala ventilacion = tip burn. No se usaron foros como fuente normativa de umbrales. Los umbrales finales se apoyan en extension universitaria, guias tecnicas y literatura tecnica.

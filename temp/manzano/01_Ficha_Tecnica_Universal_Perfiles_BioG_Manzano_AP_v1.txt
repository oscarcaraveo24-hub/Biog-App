0. CORRECCIONES Y DECISIONES DE ESTA VERSION
================================================================================

0.1 Decisión documental
La Ficha Técnica Universal y la Ficha de Perfiles/Variedades quedan en ESTE MISMO DOCUMENTO.
No se crea un documento separado de variedades. Esto sigue el Estándar BIO-G para árboles
perennes v1.3 y mantiene el patrón usado en berenjena: cultivo madre + perfiles + aliases +
etapas + rangos base + UX + mapeo técnico.

0.2 Decisión técnica central
En árboles, BIO-G NO debe usar sowingDate como eje principal.
El eje correcto es:

estado fisiológico del árbol
+ etapa/evento visible
+ ancla temporal
+ memoria del cultivo

La variedad ajusta sensibilidad, frío, fechas relativas, cosecha relativa, rendimiento relativo
y textos. La variedad NO cambia la arquitectura fenológica.

0.3 Qué se corrigió respecto al borrador anterior
- Se cambió la lógica de “perfil universal a medias” por documento madre completo.
- Se incorporan perfiles AP dentro del Universal.
- Se aterrizan IDs de código, aliases, estados, etapas, anclas y métricas permitidas.
- Se separa mejor árbol joven/no productivo vs árbol productivo.
- Se mantiene la postcosecha como etapa activa, no como cierre.
- Se agregan rangos medibles base para sensores BIO-G.
- Se agrega matriz de StageTargets base, StageWeights base y sensibilidad por etapa.
- Se agrega fuente técnica de universidades/extensión y se marca qué datos son
  conservadores/modelados para BIO-G v1.
- Se incluye una nota sobre foros: se revisaron solo como señal de nombres comunes,
  confusión real del usuario y aliases; NO como fuente para rangos agronómicos.

0.4 Qué NO se sobre-modela en v1
- No se calcula requerimiento exacto de horas frío por huerto.
- No se calcula GDD real por variedad.
- No se fuerza alternancia productiva.
- No se modela portainjerto como motor principal.
- No se modela número de frutos por árbol.
- No se receta fertilización en kg/ha dentro de este documento.
- No se inventan sensores fuera de los permitidos:
  soilMoisture, soilTemp, ph, ec, resistance, n, p, k.

5. ESTADOS DEL ARBOL Y UX RECOMENDADA
================================================================================

5.1 Estados perennes permitidos

ID: newly_planted
Etiqueta UX:
- Recién plantado
Descripción:
- Árbol colocado recientemente en campo, trasplante o reposición.
Regla:
- No producir.
- Priorizar raíz, humedad estable, baja salinidad y baja compactación.
- Ancla preferida: planting.
Confianza:
- Alta si hay fecha de plantación.
- Media si solo hay etapa visible.

ID: juvenile_non_productive
Etiqueta UX:
- Aún no produce
Descripción:
- Árbol en crecimiento estructural. Puede tener hojas, ramas y vigor, pero todavía
  no entra a producción comercial o el usuario confirma que no produce.
Regla:
- No forzar floración ni rendimiento.
- Priorizar agua, suelo, raíz, estructura vegetativa y estrés acumulado.
- Ancla preferida: stage_start o manual_stage.
Confianza:
- Media.

ID: established
Etiqueta UX:
- Árbol establecido
Descripción:
- Árbol vivo, con estructura formada, pero el usuario no confirma producción esta temporada.
Regla:
- Permitir ciclo anual si el usuario selecciona etapa visible.
- No proyectar rendimiento alto si no hay confirmación de carga.
Confianza:
- Media-baja si no hay etapa visible.

ID: productive_season
Etiqueta UX:
- En producción esta temporada
Descripción:
- Árbol con ciclo productivo anual activo: brotación, floración, cuajado, fruto,
  cosecha o postcosecha.
Regla:
- Usar etapa visible como eje principal.
- Activar memoria de estrés crítica.
- Permitir rendimiento aproximado en documento 03.
Confianza:
- Media-alta si etapa visible y fecha de inicio existen.

ID: unknown
Etiqueta UX:
- No lo sé
Descripción:
- Usuario no sabe estado.
Regla:
- No bloquear.
- Usar AP-SKIP y preguntas visuales simples.
- Alertas conservadoras.
Confianza:
- Baja al inicio; sube si hay sensor + etapa visible.

5.2 Pregunta UX recomendada para estado

Pregunta:
"¿Cómo está tu manzano actualmente?"

Opciones:
1. Recién plantado
2. Aún no produce
3. Ya produce esta temporada
4. Está establecido, pero no sé si va a producir
5. No lo sé

Mapeo:
- Recién plantado -> newly_planted
- Aún no produce -> juvenile_non_productive
- Ya produce esta temporada -> productive_season
- Está establecido... -> established
- No lo sé -> unknown

5.3 Pregunta UX recomendada si YA PRODUCE

Pregunta:
"¿Qué se ve en el árbol ahorita?"

Opciones visibles:
- Pelón / sin hojas -> dormancy
- Brotando -> budbreak
- Lleno de hojas -> vegetative_growth
- En flor -> flowering
- Tirando flor / frutito recién amarrado -> fruit_set
- Fruto verde creciendo -> fruit_fill
- Fruto madurando / listo para cortar -> harvest_maturity
- Después de cosecha -> post_harvest
- No lo sé -> unknown

Pregunta dinámica posterior:
"¿Hace cuánto empezó más o menos esta etapa?"

Anclas:
- Brotando -> budbreak
- En flor -> flowering
- Fruto madurando/listo -> harvest
- Después de cosecha -> post_harvest
- Otras -> stage_start / manual_stage

5.4 Pregunta UX recomendada si AUN NO PRODUCE

Pregunta:
"¿Qué describe mejor tu árbol?"

Opciones:
- Lo acabo de plantar -> planting_transplant
- Está echando raíz / agarrando -> root_establishment
- Está creciendo con hojas y ramas, pero no produce -> juvenile_vegetative
- No lo sé -> unknown

En esta ruta, evitar preguntar "sin hojas / reposo" como criterio principal si no aporta.
Un árbol juvenil puede estar sin hojas por temporada, pero eso no define producción.

6. ETAPAS FENOLOGICAS BIO-G DEL MANZANO
================================================================================

Tabla de etapas v1:

ID: planting_transplant
UX:
- Plantación / trasplante
Aplica en:
- newly_planted
Ancla:
- planting
Descripción:
- El árbol acaba de establecerse en campo.
Prioridad BIO-G:
- Evitar estrés por trasplante, saturación, salinidad y compactación.
No producir:
- Sí, bloquea producción.
Sensibilidad:
- agua alta, suelo alto, EC alta, resistencia alta.

ID: root_establishment
UX:
- Establecimiento radicular
Aplica en:
- newly_planted, juvenile_non_productive
Ancla:
- stage_start o planting
Descripción:
- Desarrollo de raíces finas y recuperación de trasplante.
Duración orientativa:
- 0-6 meses después de plantación, variable por clima y manejo.
Prioridad BIO-G:
- Humedad estable, oxígeno en suelo, baja salinidad.
No producir:
- Sí, bloquea producción.

ID: juvenile_vegetative
UX:
- Crecimiento juvenil
Aplica en:
- juvenile_non_productive
Ancla:
- stage_start / manual_stage
Descripción:
- Construcción de estructura, ramas, hojas, raíz y reservas.
Duración orientativa:
- Año 1-3 en sistemas modernos; puede ser más en árboles grandes o manejo extensivo.
Prioridad BIO-G:
- Vigor equilibrado, sanidad, agua, suelo.

ID: dormancy
UX:
- Reposo / pelón / sin hojas
Aplica en:
- established, productive_season
Ancla:
- stage_start / manual_stage
Descripción:
- El árbol caducifolio está en reposo invernal. Acumula frío y conserva reservas.
Prioridad BIO-G:
- No sobreinterpretar NPK; vigilar frío, heladas extremas, humedad excesiva y raíces.
Nota:
- Horas frío son contexto climático v2, no sensor BIO-G v1.

ID: budbreak
UX:
- Brotación
Aplica en:
- established, productive_season
Ancla:
- budbreak
Descripción:
- Yemas salen de dormancia; aparecen puntas verdes, hojas y estructuras florales.
Prioridad BIO-G:
- Evitar frío tardío, estrés hídrico y exceso de N.

ID: vegetative_growth
UX:
- Desarrollo vegetativo / lleno de hojas
Aplica en:
- established, productive_season
Ancla:
- stage_start
Descripción:
- Expansión de hojas, brotes y soporte fotosintético.
Prioridad BIO-G:
- Agua y nutrición moderada; no empujar vigor excesivo si hay fruta.

ID: flowering
UX:
- Floración
Aplica en:
- productive_season
Ancla:
- flowering
Descripción:
- Etapa crítica: flor abierta, polinización y sensibilidad a helada.
Prioridad BIO-G:
- Temperatura estable, agua estable, evitar saturación, estrés y salinidad.
Riesgo:
- helada tardía, calor seco, mala polinización.

ID: fruit_set
UX:
- Cuajado / amarre / frutito
Aplica en:
- productive_season
Ancla:
- stage_start o flowering
Descripción:
- Después de floración/pétalos, el fruto recién amarrado define carga potencial.
Prioridad BIO-G:
- Agua estable, evitar calor, salinidad y estrés.
Nota:
- Fruit set suele observarse 7-14 días después de caída de pétalos en guías de etapas.

ID: fruit_fill
UX:
- Llenado / fruto verde creciendo
Aplica en:
- productive_season
Ancla:
- stage_start
Descripción:
- Crecimiento de fruto, calibre, calidad y acumulación.
Prioridad BIO-G:
- Humedad estable, K/Ca/Mg en doc 05, evitar déficit y EC alta.
Nota:
- La fase temprana de crecimiento de manzana incluye división celular aproximadamente
  35-45 días después de antesis; después domina expansión celular hasta madurez.

ID: harvest_maturity
UX:
- Maduración / cosecha / fruto madurando
Aplica en:
- productive_season
Ancla:
- harvest
Descripción:
- Fruto alcanza madurez comercial. Varía por perfil, clima y mercado.
Prioridad BIO-G:
- Evitar estrés hídrico fuerte, golpe de sol, exceso de humedad y pérdida de calidad.

ID: post_harvest
UX:
- Postcosecha / después de cosecha
Aplica en:
- productive_season, established
Ancla:
- post_harvest
Descripción:
- Etapa activa de recuperación, hoja funcional y reservas para siguiente ciclo.
Prioridad BIO-G:
- No apagar alertas; guardar estrés; recuperación hídrica/nutricional.
Regla:
- Cosecha/postcosecha NO cierran el cultivo.

ID: unknown
UX:
- No lo sé
Aplica en:
- todos
Ancla:
- unknown
Descripción:
- Estado fenológico no confirmado.
Prioridad BIO-G:
- Mantener app funcionando con confianza baja/media y alertas conservadoras.

================================================================================
7. TIEMPOS FISIOLOGICOS ORIENTATIVOS
================================================================================

Estos tiempos son para visualización, calendario aproximado y mensajes. No son promesas.

7.1 Ventanas universales productivas
- Brotación -> floración: 20-50 días, según frío acumulado, temperatura y perfil.
- Floración -> cuajado visible: 5-20 días.
- Cuajado -> llenado activo: inmediato; el fruto puede tener fase temprana fuerte de
  división celular durante ~35-45 días después de antesis.
- Llenado de fruto: 60-110 días, según perfil y carga.
- Plena floración -> cosecha: 100-180 días, según variedad/perfil, clima y mercado.
- Postcosecha: desde cosecha hasta senescencia/caída de hoja o inicio de dormancia.

7.2 Entrada a producción
- Sistemas modernos/intensivos con portainjerto enanizante: puede iniciar en año 2-3.
- Golden/Red en manejo común: entrada orientativa año 3-4.
- Criolla/rayada o sistemas menos intensivos: año 3-5 o más.
- Producción plena: típicamente año 4-6+ según sistema, portainjerto y manejo.

BIO-G v1 no debe pedir edad exacta para resolver etapa.
La edad puede ayudar en rendimiento, pero no debe mandar el motor fenológico.

================================================================================
8. RANGOS MEDIBLES BASE PARA BIO-G v1
================================================================================

IMPORTANTE:
Los rangos son de monitoreo y score, no recetas. Ajustes finos de NPK van en Documento 05.

8.1 Temperatura ambiente / contexto climático
- Activación fisiológica orientativa: >7 °C.
- Desarrollo general favorable: 15-25 °C.
- Observación por calor: >28-30 °C, especialmente en floración/cuajado/llenado.
- Riesgo de helada: cerca o bajo 0 °C.
- En floración, umbrales de daño por helada dependen de estado de yema y duración.
  Guías de extensión muestran daño progresivo desde estados tempranos hasta plena flor.

Uso en BIO-G:
- Temperatura ambiente es contexto externo, no lectura del sensor de suelo.
- soilTemp sí puede influir en raíz/actividad.

8.2 Temperatura de suelo / soilTemp
- Baja actividad radicular: <7-8 °C.
- Rango operativo general raíz: 8-25 °C.
- Favorable aproximado: 12-22 °C.
- Observación: >26-28 °C en suelo superficial si se combina con baja humedad.
- Alerta: temperaturas extremas + déficit hídrico.

8.3 Humedad de suelo / soilMoisture
Interpretación preferida:
- % de agua disponible o escala normalizada por textura.
Si el sensor da porcentaje volumétrico, convertir a bandas relativas por suelo.

Rangos base:
- Bajo crítico: <45% AW
- Observación baja: 45-55% AW
- Operativo: 55-85% AW
- Optimo conservador: 60-80/85% AW según etapa
- Exceso/saturación: >90% AW o lectura persistentemente alta con mala aireación

Regla:
- Manzano necesita humedad estable, pero no saturación.
- En suelos con agua parada por más de 24 h hay riesgo de falta de oxígeno en raíz.
- Evitar alternancia fuerte seco/saturado.

8.4 pH
- Optimo BIO-G v1: 6.0-7.0
- Aceptable amplio: 5.5-7.5
- Observación: 5.0-5.5 o 7.5-8.0
- Alerta: <5.0 o >8.0, especialmente si hay síntomas o bloqueo nutricional.

Nota:
Penn State recomienda pH 6.0-6.5 para manzanos en plantaciones frutales; USU maneja
6.0-7.5 para la mayoría de frutales. BIO-G usa una banda conservadora para UX.

8.5 Conductividad eléctrica / ec
Usar como alerta conservadora por sensibilidad a sales, no como diagnóstico único.

- Seguro/normal: <1.0 dS/m
- Observación: 1.0-2.0 dS/m
- Alerta inicial: >2.0 dS/m
- Alerta fuerte: >3.0 dS/m o tendencia ascendente + estrés hídrico

Nota:
La escala general de salinidad de USU indica que 0-2 dS/m suele ser mayormente
negligible, 2-4 dS/m puede restringir plantas sensibles. BIO-G usa >2.0 como alerta
temprana conservadora en manzano.

8.6 Resistencia/compactación / resistance
- Favorable: <1.0 MPa
- Observación: 1.0-2.0 MPa
- Alerta: >2.0 MPa
- Crítico: >3.0 MPa

Nota:
2 MPa se usa como umbral general donde muchas raíces ya no crecen bien. En manzano
el problema se agrava si coincide con baja humedad, baja materia orgánica, suelo pesado
o mala aireación.

8.7 NPK relativo
No usar como dosis.

N:
- Bajo/moderado en dormancia.
- Moderado en brotación/vegetativo.
- Evitar exceso en floración/fruto porque puede empujar vigor vegetativo blando.

P:
- Importante en raíz, establecimiento, brotación y floración.
- Interpretar con pH y análisis de suelo.

K:
- Alto peso en llenado, calibre y calidad.
- Interpretar con Ca/Mg, carga y agua.

14. POLINIZACION Y CARGA: NOTAS PARA BIO-G
================================================================================

Regla agronómica:
La mayoría de los manzanos requieren polinización cruzada para producir bien.
Incluso variedades descritas como parcialmente autofértiles producen mejor con polinizador compatible.

BIO-G v1:
- No bloquear cultivo si usuario no sabe polinizador.
- En floración/cuajado, si hay bajo cuajado y no hay estrés ambiental evidente, sugerir:
  "Revisa si hay otra variedad compatible floreando cerca y actividad de abejas/polinizadores."
- No crear motor de compatibilidad varietal en v1.
- Guardar como posible factor de rendimiento/diagnóstico futuro.

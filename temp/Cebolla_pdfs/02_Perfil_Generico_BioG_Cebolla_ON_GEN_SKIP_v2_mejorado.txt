1. Proposito del perfil ON-GEN
--------------------------------------------------------------------

ON-GEN se usa cuando el agricultor quiere registrar cebolla pero no sabe o no desea especificar si es blanca, amarilla, morada, dia corto, dia intermedio, cambray/rama, almacenamiento, proceso o variedad comercial.

La funcion principal de ON-GEN es que BIO-G pueda empezar a leer el cultivo sin inventar precision falsa. En cebolla esto es especialmente importante porque una planta puede verse vigorosa y aun asi fallar en bulbo si el fotoperiodo no corresponde, si entro chica a induccion, si hubo deficit de agua, si la salinidad subio o si se siguio empujando nitrogeno tarde.

Filosofia ON-GEN:
El perfil generico no adivina, protege. Permite iniciar rapido, alerta con prudencia y deja al sistema listo para migrar a un perfil mas preciso sin borrar historial.

3. Cuando usar y cuando NO usar ON-GEN
--------------------------------------------------------------------

Usar ON-GEN:
- El usuario solo dice "cebolla".
- No conoce color, tipo, fotoperiodo, destino o variedad.
- No encuentra su variedad en el catalogo.
- Quiere avanzar rapido.
- El lote ya existe con datos incompletos.
- Solo tiene etapa manual y no sabe fecha exacta.
- La app todavia no puede resolver region/fotoperiodo con confianza.

No usar ON-GEN:
- El usuario elige cebolla blanca, amarilla, morada, cambray/rama o transicion.
- Selecciona una variedad reconocida que apunta a un perfil.
- Declara destino claro: cambray/manojo, bulbo seco/almacenamiento, proceso.
- El modulo ya necesita fertilizacion fina, rendimiento o manejo local especifico.
- El sistema detecta contradiccion fuerte de fotoperiodo y el usuario confirma el tipo correcto.

4. Supuestos agronomicos conservadores
--------------------------------------------------------------------

Parametro                         Base ON-GEN

Uso generico                       Bulbo fresco generico, sin definir color, pungencia, almacenamiento, proceso o cambray.

Inicio de induccion/bulbificacion  60-90 dias desde siembra directa o fecha base, si el fotoperiodo corresponde y la planta llego con suficiente hoja.

Inicio de cosecha                  110-140 dias como rango conservador para bulbo fresco en condiciones comparables; puede moverse por perfil, region y manejo.

Ciclo                              Intermedio conservador.

Tipo de cosecha                    1 corte + curado; no asumir multiples cosechas ni cambray.

Arquitectura asumida               Bulbo globo estandar, cuello intermedio, hoja tubular de Allium.

Sistema asumido                    Campo abierto en suelo; no hidroponia ni sustrato inerte.

Modo establecimiento default        unknown si el usuario no captura; directSeed o transplant si lo declara.

Sensibilidad asumida               Muy alta a fotoperiodo incorrecto; alta a deficit en induccion/llenado; alta a exceso de humedad en raiz/cuello; media-alta a calor; alta a salinidad en etapa joven/llenado.

Confianza inicial                  Media si hay fecha + etapa + region; baja-media si solo hay cultivo; baja si no hay fotoperiodo ni fecha.

Lo que ON-GEN NO asume:
- Color: blanca, amarilla o morada.
- Dia intermedio/largo.
- Cebolla dulce vs almacenamiento.
- Cambray/rama.
- Proceso/deshidratado.
- Tamaño objetivo de bulbo.
- Densidad, calibre, rendimiento o mercado.
- Manejo protegido, hidroponia o sustrato.
- Variedad de semilla como motor independiente.

5. Calendario y Dia 0
--------------------------------------------------------------------

El Dia 0 puede venir de siembra directa, trasplante, set/bulbillo o una fecha estimada. ON-GEN debe guardar el modo de establecimiento y no fingir precision cuando falta informacion.

establishmentMode        Cuando aplica                         Comportamiento BIO-G

directSeed               Usuario registro siembra directa.      Usar ventanas por dias despues de siembra; mas sensibilidad a emergencia, costra, maleza y stand.

transplant               Usuario registro trasplante.           Iniciar en establecimiento o vegetativo segun etapa; bajar confianza si no hay edad de plantula/charola.

set                      Usuario registro bulbillo/set.         Usar con cautela; puede acortar ciclo y aumentar riesgo de bolting si set grande o frio.

unknown                  No sabe fecha o modo.                  Usar etapa manual y bajar confianza del calendario.

Etapa BIO-G                         Ventana orientativa ON-GEN          Lectura conservadora

Germinacion                         0-7/14 dias desde siembra           Solo si viene de semilla; humedad y temperatura mandan.

Emergencia / establecimiento         7-25 dias directSeed;              Raiz joven, hoja de latigo, stand y maleza. Si es trasplante, puede empezar aqui.
                                    variable en trasplante

Desarrollo vegetativo foliar         25-60/75 dias                      Construir hojas sanas antes de induccion. N y agua ayudan, pero sin exceso.

Induccion a bulbificacion            60-90 dias                         Solo si fotoperiodo corresponde y planta tiene tamaño suficiente.

Bulbificacion / llenado              75-120 dias                        Ventana critica de agua, K, CE, raiz y sanidad foliar.

Maduracion / cuello                  105-145 dias                       Dejar de empujar hoja; vigilar cuello, N tardio, humedad y cosecha.

Cosecha                              110-150 dias segun perfil/clima     Cosechar por madurez real, no solo fecha.

Curado / fin de ciclo                Postcosecha                         Secar cuello/escamas; evitar humedad alta, golpe y pudricion.

Espigado / seedstalk                 Evento                              No es etapa productiva; registrar causa y decidir cosecha/descarte.

8. Alertas activadas en lenguaje humano
--------------------------------------------------------------------

Alerta                         Mensaje sugerido                                                                 Etapas sensibles

Riesgo de fotoperiodo           El tipo de cebolla podria no corresponder al dia de la zona. Puede haber mucha hoja y poco bulbo.     Induccion

Bulbo no avanza                 La cebolla ya esta en edad posible, pero el bulbo no se define. Revise fotoperiodo, N, agua y tamaño de planta.    Induccion / llenado

Deficit hidrico                 La cebolla puede estar corta de agua aunque no se marchite. En esta etapa eso reduce calibre.       Induccion / llenado

Exceso de humedad               Hay exceso de humedad en raiz o cuello. Puede favorecer pudriciones y mala conservacion.             Establecimiento / maduracion

Salinidad elevada               La salinidad puede limitar absorcion de agua y bajar calibre. No conviene subir fertilizante sin revisar CE.      Todas, sobre todo establecimiento/llenado

Compactacion                    Aunque haya agua, la raiz puede estar limitada por suelo duro. Esto reduce tamaño y uniformidad del bulbo.         Establecimiento / llenado

N tardio / hoja muy verde        El cultivo puede estar demasiado vegetativo. Mas nitrogeno tarde puede retrasar maduracion y engrosar cuello.      Induccion / maduracion

Calor sostenido                 El calor puede acelerar madurez y dejar bulbos mas pequenos. Vigile humedad y avance de cuello.     Llenado / maduracion

HR alta / sanidad foliar         Ambiente favorable a enfermedades foliares. Revise manchas, puntas, color plateado por trips y ventilacion.     Vegetativo / llenado

Cuello grueso o no cerrado       El cuello no esta cerrando bien. Revise N tardio, humedad, fecha, variedad y sanidad.               Maduracion

Espigado                        Hay tallo floral o riesgo de espigado. La prioridad es evaluar calidad y registrar la causa.         Vegetativo avanzado / bulbo

9. Reglas de migracion ON-GEN -> tipo especifico
--------------------------------------------------------------------

Evento                                             Migracion          Accion

Usuario selecciona blanca grano/bola               ON-GEN -> ON-01   Recalcular dia corto, ciclo intermedio, sensibilidad a cuello, N tardio y humedad pre-cosecha.

Usuario selecciona amarilla/dorada                 ON-GEN -> ON-02   Ajustar precocidad, bulbo fresco/volumen, sensibilidad a deficit en llenado y calor.

Usuario selecciona morada                          ON-GEN -> ON-03   Subir peso de calidad visual, color, curado y descarte por humedad/pudricion.

Usuario selecciona transicion/dia intermedio       ON-GEN -> ON-04   Cambiar photoperiodClass a intermediateDay; ampliar calendario; subir riesgo si region/fecha no corresponde.

Usuario selecciona cambray/rama                    ON-GEN -> ON-05   Cambiar organo objetivo a hoja+base; no exigir bulbo completo; acortar ciclo.

Usuario selecciona variedad reconocida             ON-GEN -> ON-XX   Resolver alias. Si alias no existe, mantener ON-GEN y pedir tipo/fotoperiodo.

Usuario ingresa region/fecha incompatible           ON-GEN -> ON-GEN  Mantener perfil pero bajar confianza y mostrar alerta de fotoperiodo, no sentencia definitiva.

Regla de seguridad:
La migracion NO borra historial, NO reinicia cultivo y NO cambia eventos pasados. Solo recalcula calendario, ventanas activas, sensibilidad y mensajes futuros.

13. Limites de ON-GEN en v1
--------------------------------------------------------------------

- No calcula dosis fertilizante por hectarea; eso pertenece a la guia de fertilizacion.
- No diagnostica plagas/enfermedades de forma cerrada; eso pertenece al documento de riesgos.
- No promete rendimiento; el rendimiento va en ficha separada por tipo, sistema y manejo.
- No modela precio, contrato, calibre exacto por comprador, cadena de frio o almacenamiento avanzado.
- No reemplaza analisis de suelo, agua, tejido o asesoria local.
- No cubre hidroponia ni sustrato inerte en v1.
- No debe asegurar bulbificacion si el fotoperiodo es desconocido o posiblemente incorrecto.
- No debe asumir cambray si el usuario solo dice cebolla.

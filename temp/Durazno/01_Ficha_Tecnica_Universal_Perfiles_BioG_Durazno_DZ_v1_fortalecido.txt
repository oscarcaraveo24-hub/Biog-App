0. CORRECCIONES Y DECISIONES DE ESTA VERSION
================================================================================

0.1 Decision documental
La Ficha Tecnica Universal y la Ficha de Perfiles/Variedades quedan en ESTE MISMO DOCUMENTO.
No se crea documento separado de variedades. Esto sigue el Estandar BIO-G para arboles
perennes v1.5 y el patron que ya quedo validado en Manzano y Pera:

cultivo madre
+ perfiles/variedades
+ aliases
+ etapas
+ rangos base
+ UX
+ assets
+ mapeo tecnico

0.2 Decision tecnica central
En arboles, BIO-G NO debe usar sowingDate como eje principal.

El eje correcto es:

estado fisiologico del arbol
+ etapa/evento visible
+ ancla temporal
+ memoria del cultivo

La variedad/perfil ajusta:
- requerimiento relativo de frio,
- epoca relativa de floracion/cosecha,
- sensibilidad a helada, calor, enfermedades y sanidad,
- destino de fruta,
- rendimiento relativo,
- textos,
- confianza.

La variedad NO cambia la arquitectura fenologica base.

0.3 Por que Durazno es el siguiente arbol correcto
Durazno valida que BIO-G no quedo amarrado solo a frutales de pepita como Manzano/Pera.
El durazno es:

- Rosaceae, como Manzano/Pera;
- caducifolio, con dormancia real;
- perenne, con memoria de estres;
- frutal templado;
- pero de HUESO/CAROZO, no de pepita.

Eso obliga a BIO-G a respetar una diferencia clave:

En durazno existe una subventana fisiologica muy importante dentro de fruit_fill:
- crecimiento inicial de fruto,
- endurecimiento de hueso/carozo,
- llenado final / aumento rapido de calibre.

BIO-G v1 NO debe inventar un nuevo stageId para "endurecimiento de hueso".
Debe mapearlo como subventana o contexto dentro de `fruit_fill`.

0.4 Que se corrigio respecto al borrador de durazno recibido
El borrador original ya traia muy buena base:
- cropId crop_peach_tree,
- identidad Prunus persica,
- estructura caducifolia,
- perfiles DZ-01 a DZ-05,
- sensibilidad extrema a heladas en floracion,
- alta importancia de cuajado y llenado.

Esta version lo fortalece para BIO-G:
- se aterrizan IDs de codigo estables;
- se separa "Durazno" como fruto y "Duraznero" como arbol en UX;
- se agrega `dz_skip` como perfil obligatorio;
- se conectan estados perennes oficiales;
- se usan solo etapas cerradas del estandar;
- se define que "hueso/carozo" no es stageId nuevo;
- se agregan StageTargets base;
- se agregan StageWeights base;
- se agregan aliases humanos;
- se agregan reglas de assets;
- se agregan tests minimos para Codex;
- se protege el contrato AgroRange v1.4/v1.5;
- se protege que fruit_fill no se convierta en harvest_maturity por copy UX;
- se protege post_harvest como etapa viva.

0.5 Que NO se sobre-modela en v1
- No se calcula requerimiento exacto de horas frio por huerto.
- No se calcula GDD real por variedad.
- No se crea etapa nueva para endurecimiento de hueso.
- No se fuerza portainjerto como input obligatorio.
- No se modela numero de frutos por arbol.
- No se calcula raleo automaticamente.
- No se promete rendimiento.
- No se receta fertilizacion en kg/ha dentro de este documento.
- No se diagnostican plagas/enfermedades de forma cerrada.
- No se inventan sensores fuera de:
  soilMoisture, soilTemp, ph, ec, resistance, n, p, k.

0.6 Nota critica para Durazno
El durazno es uno de los frutales donde la etapa temprana decide mucho:

- La dormancia y el frio acumulado condicionan brotacion/floracion.
- La floracion es temprana y muy vulnerable a heladas tardias.
- El cuajado puede caer por frio, lluvia, calor, baja viabilidad de flor, baja reserva o estres hidrico.
- El raleo/carga afecta calibre y calidad.
- Durante endurecimiento de hueso el fruto crece distinto y el agua/nutricion se interpreta diferente.
- En llenado final el deficit hidrico reduce calibre de forma fuerte.
- Postcosecha es muy importante porque las yemas florales del siguiente ciclo se forman en madera del año.

Regla BIO-G:
Durazno no debe tratarse como "Manzano con fruto anaranjado".
Debe ser el primer frutal de hueso/carozo real del sistema.

5. ESTADOS DEL ARBOL Y UX RECOMENDADA
================================================================================

5.1 Estados perennes permitidos

ID: newly_planted
Etiqueta UX:
- Recien plantado
Descripcion:
- Arbol colocado recientemente en campo, trasplante o reposicion.
Regla:
- No producir.
- Priorizar raiz, humedad estable, baja salinidad y baja compactacion.
- Ancla preferida: planting.
Confianza:
- Alta si hay fecha de plantacion.
- Media si solo hay etapa visible.

ID: juvenile_non_productive
Etiqueta UX:
- Aun no produce
Descripcion:
- Arbol en crecimiento estructural. Puede tener hojas, ramas y vigor, pero todavia
  no entra a produccion comercial o el usuario confirma que no produce.
Regla:
- No forzar floracion ni rendimiento.
- Priorizar agua, suelo, raiz, estructura vegetativa y formacion de madera fructifera.
- Ancla preferida: stage_start o manual_stage.
Confianza:
- Media.

ID: established
Etiqueta UX:
- Arbol establecido
Descripcion:
- Arbol vivo, con estructura formada, pero el usuario no confirma produccion esta temporada.
Regla:
- Permitir ciclo anual si el usuario selecciona etapa visible.
- No proyectar rendimiento alto si no hay confirmacion de carga.
Confianza:
- Media-baja si no hay etapa visible.

ID: productive_season
Etiqueta UX:
- En produccion esta temporada
Descripcion:
- Arbol con ciclo productivo anual activo: brotacion, floracion, cuajado, fruto,
  cosecha o postcosecha.
Regla:
- Usar etapa visible como eje principal.
- Activar memoria de estres critica.
- Permitir rendimiento aproximado en Documento 03.
Confianza:
- Media-alta si etapa visible y fecha de inicio existen.

ID: unknown
Etiqueta UX:
- No lo se
Descripcion:
- Usuario no sabe estado.
Regla:
- No bloquear.
- Usar DZ-SKIP y preguntas visuales simples.
- Alertas conservadoras.
Confianza:
- Baja al inicio; sube si hay sensor + etapa visible.

5.2 Pregunta UX recomendada para estado

Pregunta:
"¿Como esta tu duraznero actualmente?"

Opciones:
1. Recien plantado
2. Aun no produce
3. Ya produce esta temporada
4. Esta establecido, pero no se si va a producir
5. No lo se

Mapeo:
- Recien plantado -> newly_planted
- Aun no produce -> juvenile_non_productive
- Ya produce esta temporada -> productive_season
- Esta establecido... -> established
- No lo se -> unknown

5.3 Pregunta UX recomendada si YA PRODUCE

Pregunta:
"¿Que se ve en el arbol ahorita?"

Opciones visibles:
- Pelon / sin hojas -> dormancy
- Brotando -> budbreak
- Lleno de hojas -> vegetative_growth
- En flor -> flowering
- Tirando flor / frutito recien amarrado -> fruit_set
- Fruto verde creciendo -> fruit_fill
- Fruto madurando / listo para cortar -> harvest_maturity
- Despues de cosecha -> post_harvest
- No lo se -> unknown

Pregunta dinamica posterior:
"¿Hace cuanto empezo mas o menos esta etapa?"

Anclas:
- Brotando -> budbreak
- En flor -> flowering
- Fruto madurando/listo -> harvest
- Despues de cosecha -> post_harvest
- Otras -> stage_start / manual_stage

5.4 Pregunta UX recomendada si AUN NO PRODUCE

Pregunta:
"¿Que describe mejor tu arbol?"

Opciones:
- Lo acabo de plantar -> planting_transplant
- Esta echando raiz / agarrando -> root_establishment
- Esta creciendo con hojas y ramas, pero no produce -> juvenile_vegetative
- No lo se -> unknown

En esta ruta, evitar preguntar "sin hojas / reposo" como criterio principal si no aporta.
Un arbol juvenil puede estar sin hojas por temporada, pero eso no define produccion.

6. ETAPAS FENOLOGICAS BIO-G DEL DURAZNO
================================================================================

Tabla de etapas v1:

ID: planting_transplant
UX:
- Plantacion / trasplante
Aplica en:
- newly_planted
Ancla:
- planting
Descripcion:
- El duraznero acaba de establecerse en campo.
Prioridad BIO-G:
- Evitar estres por trasplante, saturacion, salinidad y compactacion.
No producir:
- Si, bloquea produccion.
Sensibilidad:
- agua alta, suelo alto, EC alta, resistance alta.

ID: root_establishment
UX:
- Establecimiento radicular
Aplica en:
- newly_planted, juvenile_non_productive
Ancla:
- stage_start o planting
Descripcion:
- Desarrollo de raices finas y recuperacion de trasplante.
Duracion orientativa:
- 0-6 meses despues de plantacion, variable por clima, suelo y manejo.
Prioridad BIO-G:
- Humedad estable, oxigeno en suelo, baja salinidad, suelo suelto.
No producir:
- Si, bloquea produccion.

ID: juvenile_vegetative
UX:
- Crecimiento juvenil
Aplica en:
- juvenile_non_productive
Ancla:
- stage_start / manual_stage
Descripcion:
- Construccion rapida de estructura, ramas, hojas, raiz y madera fructifera futura.
Duracion orientativa:
- Ano 1-2 en sistemas modernos; puede ser mas en manejo extensivo o arboles debiles.
Prioridad BIO-G:
- Vigor equilibrado, sanidad, agua, suelo.
No producir:
- Si, salvo floracion/fruta aislada sin valor comercial; BIO-G no proyecta rendimiento alto.

ID: dormancy
UX:
- Reposo / pelon / sin hojas
Aplica en:
- established, productive_season
Ancla:
- stage_start / manual_stage
Descripcion:
- El arbol caducifolio esta en reposo invernal. Requiere frio para brotacion/floracion uniforme.
Prioridad BIO-G:
- No sobreinterpretar NPK; vigilar frio, heladas extremas, humedad excesiva y raices.
Nota:
- Horas frio son contexto climatico v2, no sensor BIO-G v1.

ID: budbreak
UX:
- Brotacion
Aplica en:
- established, productive_season
Ancla:
- budbreak
Descripcion:
- Yemas salen de dormancia; aparecen puntas verdes, hojas y/o botones florales.
Prioridad BIO-G:
- Evitar frio tardio, estres hidrico, salinidad y exceso de N.
Riesgo:
- las yemas de durazno pierden tolerancia al frio conforme avanzan de hinchazon a flor.

ID: vegetative_growth
UX:
- Desarrollo vegetativo / lleno de hojas
Aplica en:
- established, productive_season
Ancla:
- stage_start
Descripcion:
- Expansion de hojas, brotes y soporte fotosintetico.
Prioridad BIO-G:
- Agua y nutricion moderada; no empujar vigor excesivo si hay fruta.
Nota:
- En durazno la luz en la copa y la poda son claves para madera fructifera del siguiente ciclo.

ID: flowering
UX:
- Floracion
Aplica en:
- productive_season
Ancla:
- flowering
Descripcion:
- Etapa critica: flor abierta, riesgo de helada, lluvia/frio y aborto.
Prioridad BIO-G:
- Temperatura estable, agua estable, evitar saturacion, estres y salinidad.
Riesgo:
- helada tardia, lluvia/frio en flor, calor seco, baja reserva, enfermedades de flor.

ID: fruit_set
UX:
- Cuajado / amarre / frutito
Aplica en:
- productive_season
Ancla:
- stage_start o flowering
Descripcion:
- Despues de floracion/petalos, el fruto recien amarrado define carga potencial.
Prioridad BIO-G:
- Agua estable, evitar calor, salinidad y estres.
Nota:
- El raleo/carga futura afecta calibre; BIO-G v1 lo maneja como contexto, no como motor automatico.

ID: fruit_fill
UX:
- Llenado / fruto verde creciendo
Aplica en:
- productive_season
Ancla:
- stage_start
Descripcion:
- Crecimiento de fruto, calibre, endurecimiento de hueso/carozo como subventana y llenado final.
Prioridad BIO-G:
- Humedad estable, K/Ca/Mg en doc 05, evitar deficit y EC alta.

Subventanas internas NO stageId:
- crecimiento inicial / division-expansion temprana;
- endurecimiento de hueso/carozo;
- llenado final / final swell.

Contrato v1.5:
- NO usar copy de cosecha, madurez o "cerca de cosecha" como identidad.
- Copy permitido: llenado, calibre, fruto verde, hueso/carozo como subventana, firmeza, balance N-K-Ca/Mg.

ID: harvest_maturity
UX:
- Maduracion / cosecha / fruto madurando
Aplica en:
- productive_season
Ancla:
- harvest
Descripcion:
- Fruto alcanza madurez comercial. La ventana de cosecha de durazno puede ser corta.
Prioridad BIO-G:
- Evitar estres hidrico fuerte, golpe de sol, exceso de humedad y perdida de firmeza/calidad.
Contrato v1.5:
- Aqui si puede hablar de madurez, cosecha, color, firmeza final, aroma, grados de madurez, mercado.

UX:
- Postcosecha / despues de cosecha
Aplica en:

- post_harvest

7. TIEMPOS FISIOLOGICOS ORIENTATIVOS
================================================================================

Estos tiempos son para visualizacion, calendario aproximado y mensajes. No son promesas.

7.1 Ventanas universales productivas
- Dormancia/frio: invierno; depende de region, variedad y clima.
- Brotacion -> floracion: 15-45 dias, segun frio acumulado, temperatura y perfil.
- Floracion: 10-30 dias orientativos.
- Floracion -> cuajado visible: 5-15 dias.
- Cuajado sensible: 5-12 dias despues de floracion.
- Llenado/crecimiento de fruto: 55-120 dias segun perfil, carga, clima y destino.
- Plena floracion -> cosecha: 80-190 dias segun perfil.
- Postcosecha: desde cosecha hasta senescencia/caida de hoja o inicio de dormancia.

7.2 Entrada a produccion
- Sistemas modernos/intensivos: puede iniciar ano 2-3.
- Criollo/regional: entrada orientativa ano 2-3; plena ano 4+.
- Temprano/bajo frio: entrada orientativa ano 2; plena ano 3+ si manejo es bueno.
- Amarillo comercial: entrada ano 2-3; plena ano 4+.
- Blanco/dulce: entrada ano 3; plena ano 4+.
- Tardio/industria: entrada ano 3; plena ano 5+.

BIO-G v1 no debe pedir edad exacta para resolver etapa.
La edad puede ayudar en rendimiento, pero no debe mandar el motor fenologico.

================================================================================
8. RANGOS MEDIBLES BASE PARA BIO-G v1
================================================================================

IMPORTANTE:
Los rangos son de monitoreo y score, no recetas. Ajustes finos de NPK van en Documento 05.

8.1 Temperatura ambiente / contexto climatico
- Activacion fisiologica orientativa: >7-10 °C.
- Desarrollo vegetativo favorable: 18-30 °C.
- Observacion por calor: >30-32 °C, especialmente en cuajado/llenado.
- Estres termico: >35 °C segun humedad, viento, carga y etapa.
- Riesgo de helada: cerca o bajo 0 °C.
- En floracion, los umbrales de dano por helada cambian segun yema, duracion y humedad.

Uso en BIO-G:
- Temperatura ambiente es contexto externo, no lectura del sensor de suelo.
- soilTemp si puede influir en raiz/actividad.

8.2 Temperatura de suelo / soilTemp
- Baja actividad radicular: <7-8 °C.
- Rango operativo general raiz: 8-25/26 °C.
- Favorable aproximado: 12-24 °C.
- Observacion: >26-28 °C en suelo superficial si se combina con baja humedad.
- Alerta: temperaturas extremas + deficit hidrico.

8.3 Humedad de suelo / soilMoisture
Interpretacion preferida:
- % de agua disponible o escala normalizada por textura.
Si el sensor da porcentaje volumetrico, convertir a bandas relativas por suelo.

Rangos base:
- Bajo critico: <45% AW
- Observacion baja: 45-55% AW
- Operativo: 55-85% AW
- Optimo conservador: 60-80/85% AW segun etapa
- Exceso/saturacion: >90% AW o lectura persistentemente alta con mala aireacion

Regla:
- Durazno requiere buen drenaje y no tolera encharcamiento prolongado.
- En floracion/cuajado, agua y temperatura pesan mucho.
- En pit hardening/endurecimiento de hueso se puede tolerar demanda hidrica diferente, pero no sequia severa.
- En llenado final, deficit sostenido reduce calibre y calidad.
- En postcosecha, estres fuerte puede afectar reservas y yemas del siguiente ciclo.

8.4 pH
- Optimo BIO-G v1: 6.0-7.0
- Aceptable amplio: 5.5-7.5
- Observacion: 5.0-5.5 o 7.5-8.0
- Alerta: <5.0 o >8.0, especialmente si hay sintomas o bloqueo nutricional.

8.5 Conductividad electrica / ec
Usar como alerta conservadora por sensibilidad media a sales, no como diagnostico unico.

- Seguro/normal: <1.0 dS/m
- Observacion: 1.0-2.0 dS/m
- Alerta inicial BIO-G: >2.0-2.5 dS/m
- Alerta fuerte: >3.0 dS/m o tendencia ascendente + estres hidrico

8.6 Resistencia/compactacion / resistance
- Favorable: <1.0 MPa
- Observacion: 1.0-2.0 MPa
- Alerta: >2.0 MPa
- Critico: >3.0 MPa

Nota:
2 MPa se usa como umbral general donde muchas raices ya no crecen bien.
En durazno el problema se agrava si coincide con baja humedad, suelo pesado, baja materia
organica, mal drenaje o saturacion.

8.7 NPK relativo
No usar como dosis.

N:
- Bajo/moderado en dormancia.
- Moderado en brotacion/vegetativo.
- Evitar exceso en floracion/cuajado: puede empujar vigor, sombra y baja calidad.
- En postcosecha puede apoyar reservas solo si analisis/contexto lo justifica.

P:
- Importante en raiz, establecimiento, brotacion, energia y floracion.
- Interpretar con pH y analisis de suelo.

K:
- Alto peso en llenado, calibre, firmeza/calidad y rendimiento.
- Interpretar con Ca/Mg, carga, agua y salinidad.

Ca/B/Mg:
- No son sensores BIO-G v1, pero deben aparecer como contexto:
  Ca para firmeza/desordenes de calidad; B para floracion/cuajado; Mg como balance.
- No inventar metricas nuevas; solo mencionar como contexto o recomendacion de analisis.

================================================================================
0. DECISION EJECUTIVA
================================================================================

PR-SKIP es obligatorio.
No es un perfil incompleto.
No significa descanso.
No significa suelo sin cultivo.
No significa arbol apagado.
No significa "sin peral".
No significa que la pera sea Bartlett por defecto.

PR-SKIP es la entrada segura cuando el usuario:
- solo sabe que tiene un peral,
- no sabe variedad,
- no sabe si es Bartlett, Anjou, Bosc, Seckel, Comice, Kieffer u otra,
- no conoce compatibilidades ni polinizadores,
- no quiere elegir perfiles,
- esta registrando rapido,
- o todavia esta aprendiendo que arbol tiene.

BIO-G debe permitir avanzar sin bloquear, con comportamiento conservador y migrable.

Regla:
El estado real del arbol y la etapa visible corrigen el comportamiento.
Ejemplo:
- Si usuario elige PR-SKIP pero estado = newly_planted, BIO-G NO proyecta produccion.
- Si usuario elige PR-SKIP y etapa = flowering, BIO-G activa sensibilidad critica de floracion.
- Si usuario elige PR-SKIP y etapa = fruit_fill, BIO-G habla de llenado/calibre, NO de cosecha.
- Si despues aprende que es Bartlett, puede migrar a pr_01_bartlett_williams sin borrar historial.

================================================================================
2. SUPUESTO BASE CONSERVADOR
================================================================================

BIO-G asume para PR-SKIP:

- Peral promedio.
- Variedad desconocida.
- Portainjerto desconocido.
- Requerimiento de frio desconocido.
- Sensibilidad media-conservadora.
- Huerto a cielo abierto.
- Manejo estandar.
- Sin informacion de densidad.
- Sin rendimiento fino.
- Sin polinizador confirmado.
- Polinizacion cruzada como riesgo/nota implicita, no como input obligatorio.
- Sin historial varietal.

El perfil NO asume:
- Bartlett.
- Anjou.
- Bosc.
- Comice.
- Seckel.
- Kieffer.
- Pera asiatica.
- Arbol adulto por defecto.
- Produccion plena por defecto.
- Edad exacta.
- Portainjerto enano o vigoroso.
- Carga de fruta.
- Dosis de fertilizacion.
- Compatibilidad polinizadora exitosa.

Regla:
El estado visible manda mas que el supuesto.
Si el usuario dice "recien plantado", el arbol es no productivo aunque PR-SKIP sea general.
Si el usuario dice "en flor", se activa etapa critica aunque no se conozca variedad.
Si el usuario dice "despues de cosecha", post_harvest sigue activo y no se cierra el cultivo.

================================================================================
3. CASOS QUE DEBE CUBRIR
================================================================================

Caso 1:
Usuario dice "tengo pera/peral" y no sabe variedad.
- profileId: pr_skip
- state: unknown o el que elija
- confidence: baja/media

Caso 2:
Usuario elige arbol recien plantado.
- state: newly_planted
- stage: planting_transplant o root_establishment
- yield: bloqueado/no productivo
- targets: raiz/agua/suelo
- alerts: no hablar de cosecha

Caso 3:
Usuario dice que aun no produce.
- state: juvenile_non_productive
- stage: juvenile_vegetative o unknown
- yield: no productivo
- targets: crecimiento estructural
- copy: arbol joven, raiz, estructura, sanidad

Caso 4:
Usuario dice que ya produce y esta en flor.
- state: productive_season
- stage: flowering
- alerts: helada, lluvia/frio, deficit hidrico, calor seco, polinizacion, fuego bacteriano
- confidence: media si solo hay etapa; media-alta si hay sensores/clima

Caso 5:
Usuario dice que tiene frutito recien amarrado.
- state: productive_season
- stage: fruit_set
- targets: agua estable, EC baja, temperatura estable, riesgo de aborto
- copy: amarre/cuajado, no llenado avanzado

Caso 6:
Usuario dice que tiene fruto verde creciendo.
- state: productive_season
- stage: fruit_fill
- targets: agua estable, K relativo, EC, calor/golpe de sol
- copy obligatorio: llenado/calibre/firmeza/calidad
- copy prohibido: cosecha/madurez/cerca de cosecha

Caso 7:
Usuario dice que el fruto esta maduro/listo para cortar.
- state: productive_season
- stage: harvest_maturity
- targets: evitar estres, calidad final, firmeza, ventana de corte
- copy permitido: madurez/cosecha/almacenamiento

Caso 8:
Usuario cosecho.
- stage: post_harvest
- no cerrar cultivo
- activar memoria y recuperacion de reservas
- copy: siguiente ciclo, hoja activa, raiz activa

Caso 9:
Luego el usuario aprende la variedad.
- migration: pr_skip -> perfil especifico
- conservar historial y memoria

================================================================================
5. CALENDARIO FISIOLOGICO PROMEDIO PR-SKIP
================================================================================

Usar solo para visualizacion, mensajes y alertas generales.

- Dormancia/frio: invierno, variable por region.
- Brotacion -> floracion: 25-50 dias orientativos.
- Floracion: 15-30 dias.
- Floracion -> cuajado visible: 5-20 dias.
- Polinizacion/cuajado: 7-14 dias.
- Llenado/crecimiento de fruto: 110-180 dias.
- Plena floracion -> inicio de cosecha: 130-200 dias.
- Ventana visual MX general: julio-octubre, variable por region y perfil.
- Postcosecha: desde cosecha hasta senescencia/caida de hoja o reposo.

Notas:
- No es promesa.
- No sustituye perfil PR especifico.
- No sustituye datos locales.
- No debe disparar alertas agresivas si el usuario no confirmo etapa.
- Si hay etapa visible, la etapa pesa mas que el calendario.

6. RANGOS CONSERVADORES PR-SKIP PARA SENSORES
================================================================================

Formato:
metric | rango operativo | observacion | alerta

soilMoisture:
- operativo general: 55-80% AW
- etapa critica floracion/cuajado/llenado: 60-85% AW estable
- observacion baja: 45-55% AW
- alerta baja: <45% AW
- observacion exceso: 85-90% AW
- alerta exceso: >90% AW o saturacion persistente

soilTemp:
- operativo general: 8-26 °C
- favorable raiz: 12-22 °C
- baja actividad: <7-8 °C
- observacion calor: >26-28 °C en suelo + baja humedad
- alerta contextual: extremo + estres hidrico

pH:
- optimo conservador: 6.0-7.0
- aceptable amplio: 5.5-7.5
- observacion: 5.0-5.5 o 7.5-8.0
- alerta: <5.0 o >8.0

ec:
- seguro/normal: <1.0 dS/m
- observacion: 1.0-2.0 dS/m
- alerta inicial: >2.0-2.5 dS/m
- alerta fuerte: >3.0 dS/m o tendencia ascendente con estres

resistance:
- favorable: <1.0 MPa
- observacion: 1.0-2.0 MPa
- alerta: >2.0 MPa
- critico: >3.0 MPa

n:
- PR-SKIP no interpreta dosis.
- bajo/moderado aceptable segun etapa.
- alerta de exceso solo si la logica general detecta desbalance + etapa sensible.
- en fruit_fill puede marcar exceso si lectura lo amerita, pero NO usar copy de cosecha.

p:
- importante en establecimiento, brotacion, floracion.
- interpretar con pH y confianza baja si no hay analisis.

k:
- importante en llenado, calibre, firmeza/calidad.
- interpretar con agua/EC/carga.

Ca/B/Mg:
- No son sensores BIO-G v1.
- Pueden aparecer como contexto: Ca para calidad/firmeza; B para floracion/cuajado; Mg como balance.
- No crear metricas nuevas.

================================================================================
9. SENSIBILIDAD CRITICA PR-SKIP
================================================================================

Sensibilidad promedio:
- Heladas tardias en floracion: alta.
- Lluvia/frio/calor en floracion: alta.
- Baja polinizacion: alta como riesgo, no diagnostico.
- Fuego bacteriano: medio-alto a alto segun clima/etapa.
- Deficit hidrico en cuajado/llenado: alta.
- Exceso de humedad en suelo: alta en raiz.
- Estres termico prolongado: medio-alto.
- Salinidad: media-alta.
- Compactacion: alta.
- Falta de frio: contexto alto si region calida y etapa irregular.
- Vigor excesivo por N: observacion, especialmente con riesgo sanitario.

Penalizacion:
- Moderada si solo hay PR-SKIP.
- Alta si etapa critica esta confirmada y sensor/clima muestran estres.
- Baja si estado/etapa son unknown y no hay datos suficientes.
- Nunca afirmar diagnostico cerrado sin confirmacion.

================================================================================
10. VENTANAS FISIOLOGICAS PR-SKIP
================================================================================

Ventana critica:
- flowering -> fruit_set

Ventana de agua:
- root_establishment -> fruit_fill
- post_harvest si hubo carga alta o estres

Ventana de raiz/suelo:
- planting_transplant -> juvenile_vegetative

Ventana de nutricion relativa:
- root_establishment
- budbreak
- flowering como balance, no empujar N
- fruit_fill
- post_harvest

Ventana de memoria:
- siempre activa
- especialmente flowering, fruit_set, fruit_fill y post_harvest

Ventana de sanidad:
- flowering y brotes tiernos: fuego bacteriano/contexto
- fruit_fill/harvest: plagas de fruto, pudriciones, dano de piel
- post_harvest: hojas/reservas/sanidad residual

13. MEMORIA DEL CULTIVO EN PR-SKIP
================================================================================

Guardar siempre:
- stressType
- severity
- duration
- stageId
- stateId
- sensorSnapshot
- weatherContext si existe
- confidence
- likelyFutureImpact
- notes

Impactos:
- estres en flowering -> posible menor cuajado.
- baja polinizacion en flowering -> posible baja carga.
- estres en fruit_set -> posible aborto/menor carga.
- estres en fruit_fill -> posible menor calibre/firmeza/calidad.
- estres en harvest_maturity -> posible perdida de calidad/cosecha.
- estres en post_harvest -> posible menor reserva y siguiente ciclo mas debil.
- estres en root_establishment -> posible arbol lento o problemas futuros de raiz.
- fuego bacteriano sospechado -> memoria sanitaria para ciclos futuros, sin diagnostico cerrado.

Regla:
Aunque el usuario migre de pr_skip a pr_01_bartlett_williams, la memoria permanece.

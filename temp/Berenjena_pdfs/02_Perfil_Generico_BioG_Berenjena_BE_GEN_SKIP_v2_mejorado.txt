 1. Proposito del perfil BE-GEN
 BE-GEN se usa cuando el agricultor quiere registrar berenjena pero no sabe o no desea especificar si es larga,
 oval/bola, rayada, blanca u otro tipo. El objetivo es no bloquear la configuracion y mantener alertas utiles desde
 el primer dia.
 Filosofia BE-GEN: este perfil no busca maximo rendimiento ni precision varietal. Busca estabilidad, proteccion de
 floracion/cuajado, bajo riesgo de error, alertas tempranas y una experiencia humana cuando la informacion del usuario
 esta incompleta.

 4. Supuestos agronomicos conservadores
   Parametro                                    Base BE-GEN

   Uso generico                                 Fruto fresco, sin definir forma/color/mercado.

   Floracion aproximada                         45-65 dias despues de trasplante; 60-85 dias si el Dia 0 fue semilla.

   Inicio de cosecha                            70-95 dias despues de trasplante; 90-120 dias desde semilla, segun clima y vigor.

   Ciclo                                        Intermedio, con cosecha progresiva.

   Densidad tipica                              12,000-20,000 plantas/ha como rango conservador.

   Altura/porte                                 Planta vigorosa de porte medio; puede requerir soporte segun variedad y sistema.

   Sensibilidad asumida                         Alta a frio, media-alta a calor/sequia, alta a exceso de humedad, media-alta a salinidad en fruto.

   Confianza inicial                            Media si hay fecha/etapa; baja si solo se registra cultivo.

 Lo que BE-GEN NO asume: forma del fruto, color comercial, mercado, calibre, numero de cortes, rendimiento exacto,
 sistema protegido/campo, variedad de semilla ni arquitectura fina.


 5. Calendario y Dia 0
 El Dia 0 puede venir de semilla, trasplante o una fecha estimada. BIO-G debe guardar el modo de
 establecimiento y no fingir precision cuando la informacion falta.

   establishmentMode             Cuando aplica                                      Comportamiento BIO-G

   seed                          Usuario registro siembra desde semilla.            Mostrar germinacion y establecimiento si la fecha lo permite.
                                                                                    Usar ventanas DAS.

   transplant                    Usuario registro trasplante.                       Iniciar en establecimiento o vegetativo temprano; usar ventanas
                                                                                    DAT.

   unknown                       No sabe fecha o modo.                              Usar etapa manual y bajar confianza del calendario.

   Etapa BIO-G                             Ventana orientativa BE-GEN               Lectura conservadora

   Germinacion                             0-7/14 dias desde semilla                Solo si viene de semilla; temperatura y humedad mandan.

   Emergencia / establecimiento            7-28 DAS o 0-20 DAT                      Raiz joven; alta sensibilidad a frio, saturacion y compactacion.

   Desarrollo vegetativo                   25-55 DAS o 20-45 DAT                    Construir canopia sin exceso de N.

   Floracion                               60-85 DAS o 45-65 DAT                    Etapa critica; calor/sequia/frio pueden tirar flor.

   Amarre / cuajado                        70-95 DAS o 50-75 DAT                    Agua estable, salinidad baja y temperatura moderada.

   Llenado de fruto                        80-110 DAS o 60-85 DAT                   Sube prioridad de K, Ca/Mg, humedad estable y sanidad.

   Cosecha progresiva                      90-120 DAS o 70-95 DAT en adelante       No fijar numero de cortes; depende del tipo y manejo.

   Fin de ciclo / senescencia              Tardio / por declive productivo          Cambiar tono: cierre, sanidad y registro historico.

 9. Reglas de migracion BE-GEN -> tipo especifico
 BE-GEN debe ser migrable. Esto permite que el usuario empiece rapido y despues refine el tipo sin perder
 historial del lote ni continuidad del dispositivo BIO-G.

   Evento                                       Migracion                        Accion

   Usuario selecciona larga / semilarga         BE-GEN -> BE-01                  Recalcular floracion, inicio de cosecha, densidad y textos de fruto
   morada                                                                        largo dominante.

   Usuario selecciona oval / bola morada        BE-GEN -> BE-02                  Ajustar contexto de fruto mas grande y calidad visual.

   Usuario selecciona rayada / listada          BE-GEN -> BE-03                  Mantener base intermedia; subir lenguaje de nicho/gourmet y
                                                                                 calidad visual.

   Usuario selecciona blanca                    BE-GEN -> BE-04                  Mantener base intermedia; evitar asumir alta superficie o
                                                                                 rendimiento mayor.

 Regla de seguridad: la migracion NO borra historial, NO reinicia cultivo y NO cambia eventos pasados. Solo recalcula
 calendario, ventanas activas, sensibilidad y mensajes futuros.

 13. Limites de BE-GEN en v1
 - No calcula dosis fertilizante por hectarea; eso pertenece a la guia de fertilizacion.
 - No diagnostica plagas/enfermedades de forma cerrada; eso pertenece al documento de riesgos.
 - No promete rendimiento; el rendimiento va en ficha separada por tipo, sistema y manejo.
 - No modela calibre, precio, color comercial exacto ni numero de cortes.
 - No reemplaza analisis de suelo, agua, tejido o asesoria local.

 14. Cierre de producto
 Frase guia: El perfil generico no adivina, acompana. BE-GEN permite que Berenjena nunca rompa la UX: el usuario
 puede iniciar rapido, BIO-G alerta con prudencia y el sistema queda listo para volverse mas preciso cuando haya mas
 informacion.

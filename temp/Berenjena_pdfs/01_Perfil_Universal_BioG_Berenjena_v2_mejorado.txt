 1. Proposito y alcance
 Este documento define la base biologica y de producto para que BIO-G interprete sensores, etapa, alertas,
 historial, fertilizacion general, sanidad y rendimiento aproximado de berenjena. No es una receta de produccion
 ni promete rendimiento. Su funcion es dar un motor estable para una solanacea de fruto con floracion, cuajado,
 llenado y cosecha progresiva.
 Decision de arquitectura: Berenjena si puede ser un cultivo madre propio, porque no es un subtipo de
 chile/tomate. Sus tipos UX - larga, oval/bola, rayada y blanca - viven dentro de crop_eggplant. La variedad o
 semilla comercial solo actua como alias hacia el perfil seleccionado.

 17. Reglas de migracion y seguridad UX
 - BE-GEN nunca debe mostrarse como perfil incompleto; debe sentirse como configuracion normal.
 - Si el usuario despues elige tipo especifico, BIO-G migra BE-GEN -> BE-XX sin borrar historial.
 - La migracion recalcula calendario, ventanas activas, sensibilidad y textos futuros; no reinicia cultivo.
 - Si el usuario no sabe fecha, se usa etapa manual y baja la confianza del calendario.
 - Si el usuario sabe tipo pero no variedad, cargar el perfil del tipo con alias Otra variedad.
 - No crear un perfil biologico nuevo por cada marca comercial salvo ficha validada.


 18. Reglas de no sobre-modelar en v1
 No modelar color comercial exacto, calibre, precio, numero de cortes, receta de fertilizante, diagnostico cerrado de
 plaga o rendimiento garantizado dentro del Perfil Universal. Esos temas pertenecen a guias o modulos posteriores.

   Tema                                        Decision v1

   Forma/color de fruto                        Solo ajusta UX y textos; no cambia por si solo el motor.

   Numero de cortes                            No se fija. La cosecha es progresiva y el historial dira continuidad.

   Fertilizacion kg/ha                         Queda para guia de fertilizacion con laboratorio y sistema.

   Plagas/enfermedades                         Quedan para documento de riesgos y modulo de sanidad vegetal.

   Rendimiento                                 Queda para ficha de rendimiento aproximado por sistema y tipo.

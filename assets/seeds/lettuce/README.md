# Assets de etapa — Lechuga (crop_lettuce)

Carpeta registrada en `pubspec.yaml` para los PNG de etapa fenológica de
lechuga. Mientras los archivos no existan, la UI cae al ícono de respaldo
(`errorBuilder`) sin romper la app.

PNG disponibles/referenciados por `LettuceEngine.heroAssetForStage`:

- `lettuce_stage_germination.png`       - E1 Germinacion
- `lettuce_stage_establishment.png`     - E2 Emergencia / establecimiento
- `lettuce_stage_vegetative.png`        - E3 Desarrollo vegetativo
- `lettuce_stage_head_formation.png`    - E4 Formacion de cabeza / madurez de hoja
- `lettuce_stage_harvest_window.png`    - E5 Ventana de cosecha
- `lettuce_stage_senescence.png`        - E6 Sobre-madurez / senescencia

Íconos de wizard pendientes en `assets/icons/wizard/`:

- `ic_lettuce.png` (madre / LE-GEN)
- `ic_lettuce_romaine.png` (LE-01)
- `ic_lettuce_mini_romaine.png` (LE-02)
- `ic_lettuce_iceberg.png` (LE-03)
- `ic_lettuce_butterhead.png` (LE-04)
- `ic_lettuce_looseleaf.png` (LE-05)
